# Структура библиотеки

В состав библиотеки входят 4 модуля:

- [consts](#consts)
- [funcs](#funcs)
- [classes](#classes)
- [exps](#exps)

## consts

Здесь объявляются все необходимые костанты

## funcs

Здесь объявляются все необходимые функции

## classes

Здесь объявляются все необходимые классы

## exps

Здесь объявляются функции и классы для сборки проекта
